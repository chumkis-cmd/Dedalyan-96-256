# Криптоанализ, прогон от 2026-07-25

Снимок вывода `python attacks/run_all.py --profile standard` на 12 ядрах.
Здесь он лежит как свидетельство: любое утверждение о запасе прочности в
корневом README можно сверить с этими логами построчно.

Параметры прогона (`scale x1`):

| Скрипт | Объём |
|---|---|
| `differential` | 200 000 пар на разность, 512 кандидатов, раунды 1–8 |
| `linear` | 400 000 текстов на маску, 9216 пар однобитовых масок, 12 перезапусков восхождения |
| `integral` | `k` до 24 (2^24 шифрований на пробу) |
| `boomerang` | 400 000 квартетов на пару (α, δ) |
| `impossible` | 500 000 пар на разность |
| `related_key` | 300 000 пар на конфигурацию |
| `key_schedule` | 400 000 случайных ключей |
| `randomness` | 8 ключей × 16 МиБ гаммы |

## Как читать

Числа в логах — это **кандидаты**, а не находки. Отдельное превышение порога
Бонферрони ничего не значит: порог рассчитан на независимые проверки, а
максимум по 9216 сильно коррелированным оценкам пробивает его регулярно.
Решает масштабный тест — перемер на `n`, `10n`, `100n` со свежими зернями.
Настоящее смещение держит величину, шум убывает как `1/sqrt(n)`.

Пример из `linear.log`: фаза 1 отметила маску на раунде 5 с корреляцией
0.02268 при пороге 0.02180. Прямая перепроверка на 40 млн выборок дала
0.000127 при пороге 0.000407 — шум. Именно после этого прогона в `linear.py`
появилась фаза `3b`, применяющая масштабный тест и к фазам 1–2.

## Итог

Глубочайший подтверждённый различитель — **раунд 4 из 16** (дифференциальный,
смещение 0.0211, подтверждён независимо из двух источников со спадом 1.04 и
1.08). Запас 12 раундов.

Отсутствие находки означает отсутствие дешёвой атаки в проверенном
пространстве, и ничего больше. Это не доказательство стойкости.

## Воспроизведение

```bash
python attacks/run_all.py --profile standard
```

Прогон выполнен с зерном по умолчанию (`0xD1CE5EED` = 3519962861). Все
генераторы в наборе детерминированы, поэтому то же зерно даёт тот же прогон;
задать другое можно флагом `--seed`.

Расходиться могут только тайминги и число процессов: объём работы делится
между ядрами, но зёрна раздаются по фиксированной схеме, так что результат от
числа ядер не зависит.
